# LXRN Templates Library

## 📁 Structure
- `/components` - React component templates
- `/hooks` - Custom hook templates  
- `/modules` - Business logic templates
- `/pages` - Next.js page templates
- `/api` - API route templates
- `/utils` - Utility function templates

## 🚀 Usage
Copy template file, rename, and fill `[Placeholder]` values.

## 📝 Template Placeholders
- `[ModuleName]` → Nama modul (PascalCase)
- `[component-name]` → Nama file (kebab-case)
- `[HookName]` → Nama hook (PascalCase with 'use' prefix)
